#  🌑 Camera-web


> Uma experiência visual futurista transformando o navegador em uma câmera digital experimental.

## 📌 Sobre o projeto

**Obscura** é uma aplicação web de câmera futurista desenvolvida utilizando tecnologias nativas do navegador.

O projeto explora recursos modernos da Web Platform, permitindo capturar imagens através da câmera do dispositivo, processar imagens utilizando Canvas e armazenar registros localmente.

A proposta é unir tecnologia, design futurista e interação em uma experiência imersiva.

---

## ✨ Funcionalidades

- 📷 Captura de imagens utilizando a câmera do dispositivo
- 🎨 Interface inspirada em estética futurista/cyberpunk
- 🖥️ Processamento de imagens com Canvas API
- 💾 Armazenamento local de registros
- ⚡ Aplicação rápida e otimizada com Vite
- 🌐 Execução diretamente no navegador

---

## 🛠️ Tecnologias

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura da aplicação |
| CSS3 | Interface e animações |
| JavaScript | Lógica da aplicação |
| Vite | Ambiente de desenvolvimento |
| Camera API | Acesso ao dispositivo |
| Canvas API | Manipulação de imagens |
| IndexedDB | Armazenamento local |

## 🚀 Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/obscura-futuristic-camera.git
```

Acesse a pasta:

```bash
cd obscura-futuristic-camera
```

Instale as dependências:

```bash
npm install
```

Execute:

```bash
npm run dev
```
